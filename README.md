I build operating systems, in Rust and C.

I'm a PhD candidate at the School of Computer Science, Peking University, and a
researcher at the [Syswonder](https://github.com/syswonder) community. I lead
[Robonix](https://github.com/syswonder/robonix), an embodied AI operating system that
exposes heterogeneous robot hardware to LLM-driven agents as typed, discoverable,
composable capabilities, and I maintain [hvisor](https://github.com/syswonder/hvisor),
a lightweight type-1 hypervisor for edge devices.

I also work upstream — LoongArch virtualization and documentation tooling in the
[Linux kernel](https://github.com/torvalds/linux), syscalls in
[Asterinas](https://github.com/asterinas/asterinas), LoongArch64 support across the
Rust ecosystem, and the [FreeBSD](https://docs.freebsd.org/zh-cn) Simplified Chinese
translation team. I co-authored the CCF Ubiquitous Operating Systems Open Community's
[Embodied AI Operating System Technical White Paper](https://gitlink.org.cn/zone/uos/source/292).

When I'm not writing systems code I write game and electronic music
([SoundCloud](https://soundcloud.com/wheatfox),
[Spotify](https://open.spotify.com/artist/1u5SE8RW4ivt3LgZR7skkO),
[Bandcamp](https://wheatfox.bandcamp.com/)), and keep an OS blog at
[oscommunity.cn](https://www.oscommunity.cn).
